本次更新内容（2026-08）

1. 页面首次打开防闪烁
- 网站会等待 Supabase 内容和页面设计加载完成后再显示。
- 避免先显示旧 HTML，约 1 秒后再跳到最新设计的问题。

2. 关于我头像尺寸
- 头像大小调整改为 10% ~ 160%。
- 支持滑杆 + 数字输入。

3. 留言板增强
- 访客可上传图片（最大 5MB）。
- 可直接在网页画布手绘留言附件。
- 留言文字可选择字体、字号、颜色。
- 图片/画作和文字样式会跟留言一起保存到 Supabase。

4. 日记阅读方式
- 使用手绘读书猫图片作为日记主图。
- 点击主图 → 展开日期列表。
- 点击日期 → 显示对应具体日记内容。
- 原有管理员日记编辑器、字体/字号/颜色、照片上传功能继续保留。

5. 我的工具
- PDF → PNG：将 PDF 每一页转换为图片。
- IMAGE → PDF：多张图片合并成 PDF。
- DRAWING BOARD：网页直接绘画、撤销、清空、保存 PNG。
- WHAT TO EAT TODAY：输入候选餐食后随机推荐今天吃什么。

部署：解压 ZIP 后，把里面所有文件上传到 GitHub 仓库根目录（index.html 在最外层）。

6. 手机端排版推荐
- 管理员登录后进入 EDIT PAGE。
- 新增 MOBILE LAYOUT RECOMMENDATIONS 区域。
- 01 RECOMMENDED：默认推荐。手机上单列、间距适中、文字和图片比例平衡。
- 02 COMPACT：紧凑模式。减少空白和间距，适合文字较多、希望少滚动的页面。
- 03 VISUAL：视觉模式。图片更大、作品和日记更突出，适合作品集/照片/日记。
- 选择后只影响 720px 以下的手机布局，不会破坏桌面端已经手动调整好的位置。
- 选择会和页面设计一起自动保存到 Supabase，所有手机访客会看到同一套移动端排版。
